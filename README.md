# choochoo Marketplace

Plugin marketplace for choochoo skills.

## What's Included

- **choochoo** — Provider-agnostic agent skills for intentional context control

## Installation

In Claude Code:
```
/plugin marketplace add kahanscious/choochoo-marketplace
/plugin install choochoo@kahanscious/choochoo-marketplace
```

## Skills

- `handoff` — Generate structured session summaries for clean transitions
- `context-manager` — Build minimal, task-relevant context before coding

See [kahanscious/choochoo](https://github.com/kahanscious/choochoo) for full documentation.
